# GartenHilfe Web-App

Responsive Garten-Web-App für Smartphone, Tablet und Desktop.

## Funktionen
- Deutsch / English mit botanischen/lateinischen Pflanzennamen
- Lateinische Namen sind über die Pflanzensuche auffindbar
- 131 gängige Pflanzen und Kulturen
- Aussaat, Vorziehen, Auspflanzen, Ernte/Blüte
- Gießen, Richtmengen und Düngung
- Schnittanleitungen mit schematischen Beispielbildern
- Krankheiten, Schädlinge und Standort-/Mangelprobleme
- geführte Symptomerkennung
- lokales Pflanzenfoto zur manuellen Diagnoseunterstützung
- standortabhängige Wetterinformationen über Open-Meteo
- Gartenkalender für alle 12 Monate
- „Mein Garten“ mit lokalen Pflanzenlisten
- Favoriten
- eigene Gartenaufgaben mit Termin und Checkliste
- Export/Import der persönlichen Gartendaten
- Gießmengen- und Kübelrechner
- Aussaat- & Pflanzplaner
- PWA-Unterstützung mit Offline-Cache

## GitHub Pages
Alle Dateien aus dem ZIP in das Repository hochladen. Danach: Settings → Pages → Deploy from a branch → main / root.

Die App benötigt für Standort/Wetter eine Internetverbindung. Die Pflanzendaten und viele Funktionen sind lokal verfügbar.

## Hinweis
Pflegeangaben sind Richtwerte. Sorte, Boden, Mikroklima, Topfgröße und Wetter können abweichen. Pflanzenschutzmittel nur nach aktueller Zulassung und Etikett verwenden.


## Deutsch / English
Die Web-App besitzt einen DE/EN-Sprachschalter. Die Auswahl wird lokal im Browser gespeichert. Navigation, Filter, Kalender, Diagnose, Rechner, Pflanzennamen und zentrale Pflegebegriffe werden entsprechend umgeschaltet.
